# v1.6.0

v1.6 is the developer workflow and reliability release.

## Highlights

- Developer Tools: workspace search, Git diff, frontmatter editing, local-link validation and backlinks.
- Reusable transformations: save named find/replace commands and apply them to the active document.
- Export profiles: compact, standard and spacious layouts for standalone HTML and PDF output.
- Safer editing: unsaved-change guard, atomic crash recovery and correct external-change conflict handling.
- Secure AI settings: OpenRouter credentials now live in the operating system credential vault.
- Markdown quality: deterministic lint auto-fix for whitespace and heading-level jumps.

## Reliability and security

- Failed Save As operations no longer activate a path or report a false success.
- Legacy `mdview.*` preferences migrate automatically to `marknote.*` without losing settings.
- File-system capabilities are restricted to the user's home scope and dialog-selected paths.
- Recovery drafts are stored in the application data directory instead of browser storage.
